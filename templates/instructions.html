Instructions to add new Student Projects:

Once logged into KAMAR, go to Reporting and click Student Lists. Open the Student List – Custom Fields option, then use the search filter at the top left to find all attending students. Next, click the Field List tab, click Select All to grab every available data column, and hit Apply. Finally, click Actions at the top left, select Export, make sure the format is set to CSV, and hit OK to save the complete file to your computer. Upload the file in the below selector.
